# Xinwu Public Processed Inputs

This directory contains the processed Xinwu input tables used by the public model configurations. The tables cover node-level demand, renewable potential and availability, grid-interface assumptions, network-proxy edges, temporal representation, technology costs, storage, flexibility, carbon factors, grid prices, and uncertainty ranges.

Use `public_input_manifest.csv` for row counts and byte sizes, `../catalog.yaml` for SHA-256 checksums and licensing metadata, and `docs/input_schema.md` for required columns.
