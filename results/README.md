# Results

This directory contains reported machine-readable study outputs and is also the destination for locally generated run records and summaries.

```text
results/summary_public/reported/   Accepted-study summary tables
results/runs/                      Generated run records
results/summaries/                 Generated summary tables
```

The reported tables cover cost–emission frontiers, system composition, storage sensitivities, flexibility ablations, uncertainty rankings, temporal robustness, spatial aggregation, network abstraction, marginal abatement costs, and validity diagnostics.

All committed result tables are available under the repository-wide MIT License.
