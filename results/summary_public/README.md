# Public Summary Outputs

The `reported/` directory contains the machine-readable summary tables associated with the accepted study. These tables support inspection of frontier points, system composition, storage and flexibility sensitivities, uncertainty rankings, temporal robustness, spatial and network checks, marginal abatement costs, and constraint-relaxation diagnostics.

`docs/results_schema.md` groups the tables by analytical role, and `data/catalog.yaml` records their byte sizes, SHA-256 checksums, and MIT licensing metadata.

All tables in this directory are available under the repository-wide MIT License.
